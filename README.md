# Farmstead Pizza – Online Restaurant Website

**Farmstead Pizza** is an interactive online restaurant website designed for a pizza place. This project was created as part of the **Introduction to Web Programming (IWP)** course to demonstrate front-end web development skills including HTML, CSS, and JavaScript.

---

## **Project Overview**

* Users can **browse the menu** and view pizza options.
* The site provides a **responsive and user-friendly interface**.
* Implemented **interactive features** using JavaScript (e.g., menu selection, dynamic content display).
* Designed with **HTML and CSS** for layout, styling, and visual appeal.

---

## **Technologies Used**

* **HTML** – Structure and layout of web pages.
* **CSS** – Styling, layout, and responsive design.
* **JavaScript** – Interactivity and dynamic behavior.

---

## **How to Run**

1. Clone or download the repository.
2. Open `main.htm` in a web browser (Chrome, Firefox, Edge, etc.).
3. Navigate through the site to view the menu and interact with the interface.
